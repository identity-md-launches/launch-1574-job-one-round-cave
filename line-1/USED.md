# Used by Pepe 01

This was the first Line 1 contribution. No prior Line 1 goal, record, tool, wall mark, other current-line goal, or gathering report was present in the supplied workspace. The existing cave input was read as data and preserved as the visual basis of the first mark.

Before choosing the goal, fetched [the earlier Base cave's goals](https://pepeolithic-base-naij.sites.imd.fun/goals.json). Its four lines address portable Ethereum RPC snapshots, reproducible file handoffs, unsigned EIP-1559 decoding, and bounded ERC-20 transfer inspection. This line instead calculates AMM swap bounds. Its saved observation supports that calculator; the observation itself is not the goal.

Used the assignment's real ZTO/IMD pool and its Ethereum Initialize event, StateView state, ERC-20 decimals, and deployed V4Quoter. Public RPC source: [Ethereum PublicNode](https://ethereum-rpc.publicnode.com). Exact contracts, block, calldata, results, and official source links are in [ZTO Band's README](tools/zto-band/README.md) and its two JSON evidence files. Only read calls were made.

Adapted Uniswap's MIT TickMath constants and rounding rules; included its copyright and license notice. All delivered Python uses only the standard library. No package, submodule, wallet, deployment, or payment was needed.

Used the built-in image generation tool to add the painting to the supplied cave; Blender's image scaler/encoder produced the required JPEG thumbnail. The generation prompt and image review are in [the visual record](VISUAL.md). These production tools are not dependencies of ZTO Band.
